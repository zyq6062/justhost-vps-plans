## 香港机房快不快：一份 2022 年的测评值得看一眼

JustHost 页面标注覆盖 41 个国家、80 个机房、21 年运营，机房都在境外，不需要走 ICP 备案流程，开通就能绑域名上线。

香港节点是大陆用户最近的选择。2022 年 12 月一份第三方测评的 traceroute 记录显示，从香港机房出发的流量先到美国洛杉矶的 he.net 节点，再经中国联通 4837 骨干网回到广州、重庆，延迟在 300 ms 以上；同一份测评里成都教育网方向走 HKIX 回程，延迟 40–73 ms。另一份测评的广州电信方向同样显示绕道洛杉矶，延迟 300 ms 上下。两份测评的结论一致：当时的香港节点不是大陆三网直连的优化线路，电信、联通方向绕美。

这份数据是四年前的，线路会调整，不能直接当成今天的结论。它说明的是风险：便宜的不限流量 VPS 通常不做大陆回程优化，宣传页上的“香港”只代表机房位置，不代表到国内的延迟。

判断方法很直接。买最短周期，拿到 IP 后做 traceroute 或 mtr，看回程是否绕美西、是否经过 59.43.x.x 这类 CN2 节点。绕美的话延迟会明显偏高，晚高峰更明显。测完不满意，JustHost 支持在用户中心换机房，把同一台机器切到其他亚太节点再测一轮，比一次买一年赌运气稳妥。

面向大陆用户的站，先按最低周期买一台测线路，确认延迟能接受再转 12 个月预付。

## 什么情况下你不该买免备案 VPS

以下三类需求，境外机房不是最优解。

**面向大陆用户的电商主站、直播、在线教育。** 这类业务对延迟和稳定性极敏感，晚高峰丢包直接影响下单和上课。境外机房回程线路不可控，出问题排查成本高，优先考虑国内备案加 CDN，预算够的话选明确标注大陆优化线路的产品。

**要接国内支付、小程序、公众号的业务。** 这些平台通常校验域名备案状态，服务器放在境外绕不开这道门槛。免备案解决的是“不办备案也能上线”，解决不了“平台要求备案”。

**纯静态的个人主页。** 先用免费托管验证需求，一个页面不值得为它养一台 VPS。等你要跑后端、要数据库、要定时任务了，再买。

反过来，个人博客、技术笔记、爬虫和定时脚本、外贸展示站、海外 API 中转、临时开发环境、练手学 Linux，这些场景对大陆延迟不敏感或者根本面向海外，JustHost 这种按磁盘计价、不限流量、可以随时换机房的机器很合适。

## 常见问题

**JustHost 的 VPS 需要备案吗？**
机房在境外，不需要 ICP 备案，开通后绑域名即可访问。免备案不等于免审核，机房所在地的法律和内容规则照样适用，违规内容会被封停。

**1 核 1G 能跑 WordPress 吗？**
能跑，但不宽裕。WordPress 加 MySQL 加 Nginx 在 1G 内存下能启动，插件一多、流量一上来容易内存耗尽。长期做内容站，直接上 Arcturus 的 2G。

**不限流量有隐藏上限吗？**
页面写的是不限流量、端口公平共享，300 Mbps 标称折合每月 93+ TB。共享端口意味着邻居跑满时你的速度会受影响，别把标称带宽当独享。

**可以换机房和 IP 吗？**
可以，两项都在用户中心自助操作。换机房对测试线路特别有用，买一台就能横向对比多个亚太节点。
